# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public issues, discussions or pull requests.

Report them privately through
[GitHub Security Advisories](https://github.com/bluepax/bluepax-cms/security/advisories/new).
Include the affected version, steps to reproduce and the impact you expect. We will acknowledge
the report, keep you updated while we work on a fix and credit you in the advisory unless you
prefer otherwise.

## Supported versions

Security fixes are released for the latest released version.
