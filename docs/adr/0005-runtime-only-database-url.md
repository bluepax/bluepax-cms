# 0005 `DATABASE_URL` 只在运行时必填

- 状态：已采纳（2026-11-24）
- 涉及：规范第 9 章（密钥只放环境变量、启动顺序），`apps/cms/src/env.ts`

## 背景

SvelteKit 3 在构建时分析路由，会按 `src/env.ts` 校验环境变量；`DATABASE_URL` 若为必填，构建与
打镜像时就必须提供一个数据库地址。规范要求密钥只放环境变量，构建阶段不应依赖它们。

## 决策

- `DATABASE_URL` 在 `env.ts` 中声明为可选，但若提供则必须是 `postgres://` 地址。
- 运行时首次取连接池时检查，未设置则报错；启动流程会立即执行迁移，所以进程在启动阶段就会退出，
  不会带着缺失的配置对外服务。

## 影响

- 构建与镜像不需要任何数据库或密钥。
- 后续新增的密钥类变量（如 `APP_SECRET`、`ENCRYPTION_KEY`）按同样方式处理：构建时可缺省，启动时必检。
