# 0007 site 模块：设置的存放与实例配置的扩展

- 状态：已采纳（2026-11-24）
- 涉及：规范第 2 章（实例配置项）、第 3 章（`site`）、第 4 章（法律主体、地点、导航）、第 8 章（即时通讯、
  邮件）、第 9 章（`ENCRYPTION_KEY`、审计）、第 12 章（编辑账号被拒绝），`packages/presets`、
  `packages/db/src/schema/site.ts`、`apps/cms/src/lib/server/modules/site`、
  `apps/cms/src/routes/(app)/settings`

## 背景

规范第 3 章列出 `site` 模块的全部设置项；第 2 章列出配置文件“站点”“语言”分组的配置项，说明配置文件与后台
设置一一对应、公司资料不进种子，并要求后台能导出当前配置。规范没有规定哪些 `site` 设置属于配置文件、字段的
具体格式、导航的层级深度，以及法律主体等站点数据的多语言文本怎样存。

## 决策

- **配置文件只含第 2 章列出的项。** `site` 分组新增发布者名称与 sameAs、品牌词、即时通讯（渠道、号码、各语言
  预填文案）；`languages` 不变。新字段都有默认值（发布者名称留空表示使用站点名称），旧配置文件仍然有效。
  即时通讯文案的语言必须是内容语言；删除内容语言时，同一事务中删去该语言的文案。
- **后台修改配置分组时整体重新校验**（`updateInstanceConfig`，带事务级 advisory lock），后台的状态因此总能
  写成一份有效的配置文件；“设置 → 实例配置”显示并下载这份 YAML，不含任何密钥。
- **站点数据只在后台录入，不进配置文件与导出**：联系方式、社媒、页脚文字、主题色、SMTP、法律主体与地点、
  导航。它们是公司资料或含密钥。前五项存为 `settings` 表的 `site.*` 行；法律主体、地点与导航按第 4 章存表
  `legal_entities`、`entity_locations`、`nav_items`（迁移集 `site`）。
- **多语言文本存为 JSONB**（键为 BCP 47 代码，空文本不存），不建 `_translations` 表：第 4 章的翻译表用于有
  按语言的状态、slug 与发布时间的可路由内容，站点数据没有这些列。删除内容语言后旧文本保留，重新添加该语言
  即可恢复；必填的文本（法定名称、菜单名称）要求主语言有值。
- **渠道与平台用小写标识**（如 `whatsapp`、`linkedin`），不固定列表，前台按标识生成链接与图标；后台只给出
  常见标识作为输入提示。
- **地点**：地址按语言分街道、城市、省 / 州；邮编、国家（ISO 3166-1 两位代码）、电话、邮箱不分语言；营业时间
  用 schema.org `openingHours` 写法；纬度与经度成对填写。法律主体的登记号与税号各有公开开关，默认不公开，
  不公开的号码不经接口下发。
- **导航**分 `header` 与 `footer` 两个菜单，最多三级；链接为前台路径、http(s) 网址、`mailto:` 或 `tel:`，留空
  表示分组标题（如页脚栏目）。菜单项不能移到另一菜单；删除菜单项同时删除其下级。指向页面、文章等内容的链接
  随这些模块加入。
- **SMTP**：服务器、端口、加密方式（STARTTLS / TLS / 不加密）、用户名、密码、发件地址；发件人名称固定为
  “BluePax CMS”（第 1 章）。密码用 `ENCRYPTION_KEY` 以 AES-256-GCM 加密存储，界面只显示“已设置”，留空保持
  不变，可单独清除；审计日志只记录密码被设置、清除或保持。
- **权限**：一个设置类权限点 `site.manage`，默认编辑角色没有。设置页的加载、所有表单动作与配置下载都先检查它，
  界面与接口同样返回 403（第 12 章），并有覆盖全部设置路由的测试。
- **审计**：设置修改记为 `site.update`（目标为设置键，详情只列出变化的字段名，不含值）；另有
  `site.entity_*`、`site.location_*`、`site.nav_*`、`site.smtp_clear` 与 `site.config_export`。

## 延后

- 标志、网站图标（由正方形 PNG 生成 favicon / Apple Touch / PWA 图标）与发布者的标志或头像依赖 media 模块，
  随它加入；博客的 Person 发布者关联主作者随 posts 模块加入。
- `site.updated` Webhook 已在清单中声明，M2 实现 Webhook 后发送。
- `GET /site` 随 Delivery API 实现，读取本模块的数据。
- 发信（含“发送测试邮件”与邮件重置密码）随 worker 的邮件任务加入。
- 被询盘归属或区域分部引用的法律主体不可删除，随这些模块加入。

## 影响

- 新增配置项时同步更新 `instanceConfigSchema`、`examples/config/*.yaml` 与本记录；配置文件格式仍为 `version: 1`。
- 以后的模块若需要按语言的可路由内容，仍按第 4 章建 `_translations` 表；只有少量文本的站点数据沿用 JSONB。
