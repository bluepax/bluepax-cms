# 架构决策记录（ADR）

记录实现过程中对[设计规范](../spec/README.md)的解释、补充或偏离，以及背后的原因。
规范仍是唯一实现依据：一条决策若改变了规范要求的行为，先改规范，再在这里记录原因。

格式：每条一个文件 `NNNN-标题.md`，包含「状态 / 背景 / 决策 / 影响」。状态为「已采纳」「已替代（见 NNNN）」或「已废弃」。
